- **fix(costs):** Cost Explorer no longer renders `$0.00` or `—` for OAuth / noauth coding-plan providers with non-zero token activity. Added pricing blocks for `kc` (Kilo Code), `oc` (OpenCode Free), and a regression-guard note for `minimax` (whose pricing already lives in `regional.ts`). Pass-through upstream models (Claude Opus/Sonnet, GPT-5.6 SOL/Terra/Luna, DeepSeek v4, GLM-5.2, Qwen3.7-Plus, Kimi K3, MiniMax M3/M2.7/M2.5/M2.1) bill at the upstream $/MTok rate, matching what `kiro:` and `cc:` already do; genuinely free models (Kilo `free` router, OpenCode `*-free`) are explicit `$0`rows so the UI shows`$0.00`not`—`. Over 30d, this recovers the cost signal for ~284M tokens (Kilo Code 11.6M, OpenCode Free 106M, Minimax Coding 165M) that were silently zero-billed. Test coverage: `tests/unit/pricing-coding-plan-rates.test.ts`.
