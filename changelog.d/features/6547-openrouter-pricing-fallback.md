- **fix(costs):** Cost Explorer now shows meaningful cost estimates for flat-rate / coding-plan providers (Minimax Coding, GLM Coding, Kiro, Kilo Code, OpenCode Free, Qwen Web, etc.) instead of $0.00. When a model has no local pricing row, the system falls back to OpenRouter's public catalog to look up the upstream list price. Model-name normalization handles provider prefixes (e.g. `anthropic/claude-3-opus` → `claude-3-opus`), case-insensitive matching (e.g. `MiniMax-M3` → `minimax-m3`), and dot/hyphen variants (e.g. `mistral-medium-3.5` → `mistral-medium-3-5`). The `flatRateAsZero: true` opt-in was removed from the analytics surfaces so the per-token estimate flows through. The flat-rate check itself stays in place for budget / quota / routing paths.
